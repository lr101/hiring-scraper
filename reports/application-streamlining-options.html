Where to invest first

1. Capture missing facts and reuse answers

Relevant work dates, professional achievements, work authorization, salary, notice period and work style. Reuse the existing skills, language and evidence profile.

2. Add “Prepare application”

Begin with a ChatGPT handoff, then add integrated generation and reviewed DOCX/PDF export. Preserve the master CV and attach the approved version to each application.

3. Improve the personalized shortlist

Broad discovery currently ranks independently of profile fit. Reuse existing multilingual search, add evidence-based reranking, collect skip reasons and move profile rebuilding to background work.

4. Pilot extension autofill on selected providers

Measure field accuracy and corrections on representative forms. Basic text mapping is feasible; uploads, custom widgets, logins and multi-step flows require further work.

Evidence from this review22 synthetic matching evaluations and 3 synthetic browser forms; 47 existing Python tests and 2 Node checks passed.No account login, model generation or live employer form was tested. Zero employer requests and submissions. No measured time savings or recommendation uplift yet.
