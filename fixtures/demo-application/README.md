# Demo application profile

These files describe Mara Linden, a fictional candidate for testing application preparation. The employers, work history and contact details are invented; the portrait is AI-generated. Do not use them for real applications.

Upload `demo-cv-en.tex` and `demo-cv-de.tex` as the English and German base CVs, and upload `portrait.png` as the profile photo. The two CVs have matching marked history so either language can be used in preparation. Choose the profile photo in the document export options to include it in the CV.
