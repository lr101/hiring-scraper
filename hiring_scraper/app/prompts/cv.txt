Task: tailor the CV to the posting. Preserve verified employers, titles, dates and section
order. Identify the core work the employer is hiring for and map it to the strongest evidence.

Headline and profile
- Write a one-line headline of at most 70 characters, preferably 45–60. Name the posting's
  role family using terms the evidence supports. Use a functional focus rather than claiming
  an unverified job title, seniority level, tenure, or ownership.
- Write one compact profile paragraph of about 35–50 words in implied first person (no I, I'm,
  I've or ich). Use two sentences, with no more than one concrete example in each.
  Lead with the strongest relevant evidence so it is visible on page one, even when the
  project itself appears later. Mention the applicant's concrete method or output where it
  directly addresses a core responsibility, especially if it is elsewhere on the CV.
  Connect two complementary strengths and name the actual stage or context. Synthesize
  across evidence instead of paraphrasing a bullet. Save motivation for the letter.
- Cite the actual work supporting each claim. If the profile names a past employer, cite a
  bullet or intro from that entry. Keep any evidence gap visible in the scope of the wording.

Entries
- For each listed entry, select and reorder its bullets by relevance, including education
  projects. Cite the original bullet for every rewrite and any career evidence that supplies
  further verified detail. Lead with the work closest to the hiring responsibilities rather than
  the most impressive result in a less relevant area. Use only evidence from the same employer
  or project.
- Return between one fewer and one more bullet than the base count, with at least one. Give
  each bullet a distinct responsibility: separate its action and purpose from the other
  bullets under that entry. Before writing, give each bullet a different topic and choose
  a single place for overlapping facts such as coordination, requirements or feedback.
  For example, when several bullets concern program work, distinguish partner relationships,
  event delivery, and participant operations instead of listing general coordination twice.
  Use the lower end of the count range when that makes the responsibilities clearer.
- Start with a direct verb and concrete object. Use consistent CV voice without explicit
  pronouns. Aim for 18–28 words for most bullets and 25–40 for project bullets that need
  context. Use parallel objects and concise clauses, especially when listing artifacts.
  In German, use a direct active verb where a reflexive construction sounds indirect.
  For joint work, use a structure like "Wirkte an … mit" or "Trug zu … bei".
- Retain the details that distinguish each cited source, such as named collaborators,
  languages used, tools, drawings or other deliverables, suppliers, scope and verified metrics.
  Keep the original distinctions between actions, methods and outcomes. State details once,
  where they best substantiate the distinct responsibility. Avoid restating an action or
  purpose in the same bullet.
- Use one self-contained bullet per labelled project. Preserve a short project lead_in ending
  with a colon and merge related details into that bullet. Do not follow a labelled project
  bullet with an unlabelled continuation. Use an empty lead_in for ordinary work bullets.
- Keep degree names in education headings. Do not repeat the degree in prose or project bullets.

Skills
- Return the existing unit ids in relevance order in unit_ids and ids to hide in hidden_ids.
  Hide lower-value items to keep the section readable.
- Use additions for up to four new competency items across the CV, or an empty list. Use a
  short phrase with posting terminology and cite the applicant's evidence ids for every term.
  Use at least one substantive posting term, and pick the rest of the phrasing from the cited
  evidence with only light inflection. The posting itself is not evidence. Keep scope
  qualifiers, and omit synonyms or duplicates of existing competencies.
