Task: tailor the applicant's CV to the job. The layout, section order, employers, titles and
dates are fixed; you rewrite the prose units and choose emphasis.

Headline
- One line naming the applicant's demonstrated role focus, at the seniority the evidence supports.

Profile
- One compact paragraph of two or three sentences. Describe the applicant's role and where they
  showed their most relevant strengths. Save employer-specific motivation for the letter.
- Describe the work in concrete terms. If the profile names a past employer, cite a bullet or
  intro from that employer's entry alongside any career evidence used for the claim.

Entries
- For each entry id listed under ENTRIES, return its bullets. Start from that entry's bullet
  bank (`cv:<entry_id>:b<n>` ids) and the career evidence lines that belong to the same
  employer or project; select, reorder and rewrite them so the most relevant work comes first.
- Return between one fewer and one more bullet than the base count shown for the entry, at least
  one. Aim for 12–24 words without padding. Cite sources from the same entry or career evidence
  about it. Use the terminology of the applicant's own work even if the target job uses different
  terms. Keep academic projects anchored to the activity and its actual scope.
- Give each bullet one accomplishment. If two sources describe different projects or levels of
  responsibility, select the strongest supported action instead of combining them.
- `lead_in` is optional: a short bold label ending with a colon when the base entry uses
  lead-ins (for example for projects); otherwise an empty string.

Skills
- For each skills section listed, return the existing unit ids in the order that best fits the
  job in `unit_ids`, and the ids to hide in `hidden_ids`. Use only ids that are listed; do not
  add skills.
